# futari-kakeibo（共同家計簿）

2人で使う共同家計簿のスマホ向け画面です。

- 画面：このリポジトリ（GitHub Pages）　https://k2-architect.github.io/futari-kakeibo/
- データ：スプレッドシート「共同家計簿」にひも付いた Apps Script。画面からは JSON を POST して読み書きします
- ログイン：Google アカウント。許可した2人のメールアドレスだけが使えます

## ファイル

| 場所 | 中身 |
| --- | --- |
| `index.html`、`assets/` | 画面 |
| `config.js` | OAuth クライアントID と API の URL |
| `icons/`、`manifest.webmanifest` | ホーム画面のアイコンと表示名 |
| `tests/` | 架空データでのテスト |
| `gas/` | Apps Script のソース。**このリポジトリには入れていません**（手元のフォルダだけにあり、clasp で同期します） |

`gas/` の中身は次のとおりです。

| ファイル | 中身 |
| --- | --- |
| `kw_api.js` | 画面からの POST を受ける入口と、ログインの確認 |
| `kyodo_webapp.js` | シートの読み書きと集計（`kw_` で始まる関数） |
| `コード.js` | 初期設定・メニュー。触らない |
| `kyodo_page.html` | 前の画面。旧デプロイ（バージョン4）用に残してあるだけ。触らない |

## 初期設定（最初の1回だけ）

1. Google Cloud の OAuth クライアント（家計ダッシュボードと同じもの）を開く。
   - 承認済みの JavaScript 生成元に `https://k2-architect.github.io` があることを確かめる。
   - 承認済みのリダイレクト URI に `https://k2-architect.github.io/futari-kakeibo/` を足す。
   - 同意画面が「テスト中」のときは、テストユーザーに2人のメールアドレスを入れる。
2. Apps Script のエディタ（共同家計簿のスプレッドシート →［拡張機能］→［Apps Script］）で、`kw_api.gs` の `kwApiSetup` を実行する。権限の画面では、すべての項目にチェックを入れて許可する。
3. ［プロジェクトの設定］→［スクリプト プロパティ］で、次の2つを2人分に書き換える。

   | プロパティ | 値の例 |
   | --- | --- |
   | `ALLOWED_EMAILS` | `taro@example.com,hanako@example.com` |
   | `USER_MAP` | `{"taro@example.com":"（設定シートの1人目の名前）","hanako@example.com":"（設定シートの2人目の名前）"}` |

   - 名前は、スプレッドシートの「設定」シートにある2人の名前と、1文字も違わないようにする。
   - `USER_MAP` は、記号（`{` `}` `"` `:` `,`）をすべて半角で書く。
4. `kwApiCheck` を実行して、実行ログが次のようになっていることを確かめる（シートには書き込みません）。
   - 「使ってよい人：2人。そのうち名前が決まっている人：2人（正常）」
   - 「API を通した結果：同じ」
   - 「ログインなしで呼んだとき：AUTH_REQUIRED」
5. 2人それぞれの iPhone の Safari で https://k2-architect.github.io/futari-kakeibo/ を開いてログインし、共有ボタン →「ホーム画面に追加」。

## Apps Script のコードを直したとき

コードを変えても、デプロイを新しいバージョンにしないと `/exec` の URL は古いコードのままです。

```
node tests/api.test.js
shasum -a 256 -c tests/untouched.sha256   # 触らないファイルが変わっていないことを確かめる
cd gas
clasp push
clasp create-deployment -i AKfycbynAicqIWPRsMA6HwVnAg05QzvtCb9UvFk4luyyT4pZiIPji2S6QgVG9KYpyYC7Yl56WQ -d "説明"
```

エディタから行う場合は、［デプロイ］→［デプロイを管理］→ API 用のデプロイを編集 → バージョン「新しいバージョン」→ デプロイ。どちらの方法でも URL は変わりません。

**旧デプロイ（バージョン4）は、この手順で更新しないでください。** 一覧で説明が「v4 元の画面」になっているものです。

## 画面を直したとき

`main` に push すると、1〜2分で GitHub Pages に反映されます。ホーム画面のアプリは、一度閉じて開き直すと新しい画面になります。

## 元に戻す（ロールバック）

- **画面**：`git revert <コミット>` して push する。
- **API**：［デプロイを管理］→ API 用のデプロイを編集 → バージョンを前の番号に戻す。
- **前の共同家計簿**：旧デプロイ（バージョン4）は残してあります。URL は Apps Script の［デプロイを管理］で確認できます。

## ログインを切る（セッションの失効）

- **2人ともログインし直しにする**：エディタで `kwApiNewSecret` を実行する。それまでのログインはすべて使えなくなります。端末をなくしたときはこれを行います。
- **使える人を変える**：スクリプト プロパティの `ALLOWED_EMAILS` と `USER_MAP` を書き換える。外した人は、ログイン済みでもすぐ使えなくなります。
- ログインは30日で切れます。切れたら、もう一度「Google でログイン」を押します。

## うまくいかないとき

- **ログインの後に何も起きない・画面が白くなる**：ログイン画面の「うまくいかないときは、ページを移動してログイン」を使う。
- **LINE などのアプリの中で開いた**：Google のログインが使えません。Safari で開き直す。
- **「このアカウントでは使えません」**：`ALLOWED_EMAILS` に入っていないアカウントでログインしています。
- **設定の「ログイン中」にメールアドレスが出る／「払った人」が最初から選ばれていない**：`USER_MAP` にそのアカウントがないか、名前が「設定」シートと違っています。
- **「エラーが発生しました」が続く**：`kwApiSetup` をまだ実行していないか、権限を許可していません。
